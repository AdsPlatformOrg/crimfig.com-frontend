# frontend/web/ads — CrimFig Ads Portal

**Subdomain:** `ads.crimfig.com`
**Framework:** Next.js 15 (App Router) + TypeScript
**Purpose:** Ads campaign management, analytics dashboard, Paystack billing.

## Stack
- Next.js 15 (App Router)
- Poppins font via `@fontsource/poppins`
- Crimfig Design System tokens from `frontend/shared/design-tokens`
- `next-intl` for internationalization
- `recharts` for analytics charts

## Setup
```bash
pnpm install
pnpm dev
```
