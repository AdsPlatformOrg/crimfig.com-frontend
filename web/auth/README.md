# frontend/web/auth — CrimFig Auth Web App

**Subdomain:** `auth.crimfig.com`
**Framework:** Next.js 15 (App Router) + TypeScript
**Purpose:** Central SSO interface — Login, Sign Up, MFA, Organization Management, App Consent flows.

## Stack
- Next.js 15 (App Router)
- Poppins font via `@fontsource/poppins`
- Crimfig Design System tokens from `frontend/shared/design-tokens`
- `next-intl` for internationalization
- `@tanstack/react-query` for server state

## Setup
```bash
pnpm install
pnpm dev
```
