# CrimFig Chibi Ninja Avatars

Twelve square, transparent 512 × 512 WebP avatars derived from the CC0 asset pack
[“2D Chibi Ninja - 8 Actions”](https://opengameart.org/content/2d-chibi-ninja-8-actions)
by [ashuuya](https://opengameart.org/users/ashuuya).

- **License:** [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- **Commercial use:** allowed under CC0.
- **Attribution:** not required by the license; displayed voluntarily in the CrimFig profile
  attribution panel because the product requests it.
- **Modifications:** heads/shoulders cropped from idle/walk frames, centered on transparent
  square canvases, nearest-neighbor upscaled, and the blue cloth recolored per avatar.
- **No third-party characters, franchise marks, or logos** are included.

The source archive is `ashuuya_chibi-ninja-2d.zip` with SHA-256
`97db9c3f79ae255950a317e4eb8f47aa972367ad2968dbbae3bcb44f8674c38a`.
See `manifest.json` for per-asset source frames, palettes, alt text, and the exact license
notice retained at verification time.

Compatibility note: the manifest/attribution text is for the asset collection. The UI may
show a shortened credit summary with a full attribution modal; the source and license links
must remain available in that modal.
