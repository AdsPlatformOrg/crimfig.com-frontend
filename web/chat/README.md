# frontend/web/chat — CrimFig Chat Client

**Subdomain:** `chat.crimfig.com`
**Framework:** Next.js 15 (App Router) + TypeScript
**Purpose:** Real-time chat client — rooms, direct messages, media sharing.

## Stack
- Next.js 15 (App Router)
- `socket.io-client` for real-time messaging
- Poppins font via `@fontsource/poppins`
- Crimfig Design System tokens from `frontend/shared/design-tokens`
- `next-intl` for internationalization

## Setup
```bash
pnpm install
pnpm dev
```
